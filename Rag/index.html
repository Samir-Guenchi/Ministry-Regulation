Innovative Architecture

Seven novel components working in concert to achieve state-of-the-art RAG performance

🔄

Self-Reflective Iterative Retrieval

The system scores its own retrieved evidence using an LLM judge, then re-queries with refined terms if confidence is below threshold — up to 3 passes.

Novel Contribution
⚡

Dual-LLM Orchestration

Groq (llama-3.3-70b) handles ultra-fast reasoning tasks — query expansion, relevance scoring, validation. Gemini synthesizes the final answer.

Dual Pipeline
🔀

RRF Ensemble Retrieval

BM25 keyword retrieval and TF-IDF semantic retrieval are independently ranked then fused using Reciprocal Rank Fusion for superior recall.

Hybrid Retrieval
📅

Temporal Evidence Weighting

Evidence from more recent regulations is scored higher. Query mentions of specific years further boost corresponding document relevance.

Temporal Reasoning
🔗

Evidence Triangulation

Claims corroborated by multiple independent year-sources receive a "corroborated" badge. Single-source claims are marked tentative.

Reliability
🌐

Cross-Lingual Query Normalization

Queries in Arabic, French, English, or Algerian Darija are all handled natively. Answers are always returned in the user's own language.

Multilingual
✅

Consistency Validation

After synthesis, Groq performs a fact-check pass to ensure the generated answer is consistent with the retrieved evidence — flagging hallucinations.

Anti-Hallucination
📚

Citation Chain Construction

Every evidence chunk used in synthesis is tracked with year, title, and relevance score — producing a verifiable citation chain for each answer.

Explainability

SPIRAL-RAG Pipeline

Seven sequential stages from query to verified, cited answer

1

Language Detection & Cross-lingual Normalization

Input language detected (Arabic / French / English / Darija). Query concepts are translated to canonical form for retrieval.

langdetect heuristics
2

Adaptive Query Expansion

Groq generates 3 alternative query variants using different terminology and perspectives, maximizing corpus coverage.

Groq llama-3.3-70b
3

Parallel Hybrid Retrieval

BM25 and TF-IDF semantic retrieval run in parallel over all query variants. Results fused with Reciprocal Rank Fusion.

BM25 + TF-IDF → RRF
4

Self-Reflection & Confidence Scoring

Groq scores the relevance of each retrieved passage (0–1). If average confidence < 0.65, queries are refined and retrieval repeats.

Groq llama-3.3-70b · max 3 iterations
5

Temporal Weighting & Evidence Triangulation

Evidence re-ranked by recency and multi-source corroboration. Top-8 chunks selected for context window.

Temporal scorer + triangulation
6

Adaptive Synthesis in User Language

Gemini generates a structured, cited answer in the user's detected language with [REF-N] inline citations.

Google Gemini 1.5 Flash
7

Consistency Validation & Citation Chain

Groq fact-checks the answer against retrieved evidence. Full citation chain assembled and returned with confidence score.

Groq llama-3.3-70b · verification
